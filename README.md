## About

A static, responsive marketing site for [IntelliCredit AI](https://github.com/manav-Mnv/intelli-credit-ai-1.0). It explains what the platform does and walks through how it turns raw financial documents into a Credit Appraisal Memo.

## Pages

| Page | Content |
| --- | --- |
| [`index.html`](index.html) | The problem, the solution, system architecture, the data-processing pipeline, the hackathon's three pillars, and the API |
| [`architecture.html`](architecture.html) | Folder structure, visual system diagram and Docker setup |

Built with plain HTML and CSS, Font Awesome icons and the Inter typeface. It is mobile-responsive.

## Run locally

Open `index.html` in a browser. No build step.
